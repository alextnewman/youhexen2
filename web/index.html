Launch

Starting the game hides the launcher chrome and asks the browser for fullscreen. Press ☰ in-game to leave fullscreen or return to the launcher; with a controller connected the ☰ button steps aside and Start opens the menu.

Renderer

WebGlideNitro is the primary renderer. It is a native WebGPU path that builds its own batched scene geometry and preserves Hexen II's indexed palette and colormap semantics. The classic 8bpp Software renderer remains available as a correctness reference and presents its indexed framebuffer through WebGPU.

The engine bundle is chosen once at launcher load. Changing this reloads the launcher; changes made during play take effect on the next launch.

Performance capture

Collects 128 raw frames without drawing over the game. Show the launcher after a few seconds, then copy the report for analysis.

The choice applies on the next launch. Reports update once per 128 rendered frames.

Phone controls

Touch controls appear automatically on touch-only devices — iPhone, and iPad with no keyboard, trackpad, or controller attached. Landscape is recommended. The left pad moves, the right side looks, and buttons attack, jump, use, switch weapons, and open the menu.

Optional during touch play. Compatible physical controllers also work when the browser exposes their motion sensors.

Notes for iPadOS

  • Install via Safari → Share → Add to Home Screen.
  • iPad keyboards have no Escape key, so the engine treats ` as Escape; Shift+` (~) still toggles the console. Set in_key_backquote_escape 0 to restore the classic behaviour.
  • Pointer Lock is currently unavailable on iPadOS Safari; external keyboards and mice still help.
  • Standalone mode is the practical target on iPadOS; it is close to fullscreen but still obeys system safe areas. Starting the game hides the launcher chrome either way.
  • Updates install when the launcher opens or returns to the foreground. Imported game data and saves are preserved.
  • Storage persistence is best-effort; avoid clearing Safari website data for this app, and periodically confirm persistence in the Storage panel above.
Tap/click the canvas to focus input. On platforms without Pointer Lock (notably iPadOS Safari), mouselook remains limited.

Game menu

iOS Safari does not provide Pointer Lock, so touch look sends relative deltas straight to the engine. On a hardware keyboard, ` acts as Escape and Shift+` (~) opens the console.

  • Left pad: move and strafe
  • Right side: drag to look
  • Atk / Jump / Use: primary action buttons
  • ◀ / ▶: previous and next weapon
